# Keymap diagrams

Generated by [keymap-drawer](https://github.com/caksoylar/keymap-drawer) and
committed here. CI regenerates them on every push (the `keymap-diagrams` job in
`.github/workflows/build.yml`) and commits the result back, so edits to these
SVGs by hand will be overwritten.

| File | Keyboard | Physical layout |
| --- | --- | --- |
| `corne-42-full.svg` | Corne 42 | keymap-drawer's stock `corne` |
| `crosses-42-full.svg` / `crosses-42.svg` | Crosses | `gggw_crosses_42_layout` via `config/crosses-info.json` |
| `corne-min-full.svg` | Corne Min | stock `corne` — shares `base.keymap` and the 42-key foostan layout |
| `toucan2-full.svg` | Toucan2 | `toucan_42_layout` via `config/toucan-info.json`, converted from beekeeb's `zmk,physical-layout` node |

Regenerate locally with `just draw` (all four), or one at a time:
`just draw-corne`, `draw-crosses`, `draw-corne-min`, `draw-toucan2`.

## Reading a diagram

keymap-drawer does not emit a legend, so:

| What you see | What it means |
| --- | --- |
| **Tinted key** (`rect.held`) | Hold this to reach the layer shown. Each layer highlights its own activator, so the tint moves between layers. |
| **Faded key** (`.trans`, 50% opacity) | `&trans` — falls through to the layer underneath. |
| **Centre label** | Tap behaviour. |
| **Label below centre** | Hold behaviour (hold-taps, layer-taps, mod-morphs). |
| **Small upper-right label** | Shifted behaviour. |
| **Dashed outline** (`path.combo`) | Combo. **Nothing currently draws these** — see below. |

Styling lives in each keyboard's `keymap-drawer/*.yaml` under
`draw_config.svg_extra_style`, with dark-mode overrides in `svg_style_dark`.
`dark_mode: auto` emits both palettes plus a `prefers-color-scheme` query, so a
single SVG suits a light or dark background.

## Known gap: combos are not drawn

`config/combos.dtsi` defines two combos (`capsword`, `smart_mouse`) and neither
appears in any diagram. `zmk_keymap_extractor.py` has no combo handling — it
emits layers only, so the `combos` node never reaches keymap-drawer. The combo
styling in the YAML configs has therefore never had anything to style.

Tracked in the vault as `keymap-drawer-combos-not-drawn`.
